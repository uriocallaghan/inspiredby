#  Chloroflurocarbon-12 (F12) hemispheric and global monthly means from the NOAA/GML
#  halocarbons program.  The following data is a combined data set from two or more measurement programs.  
#  Weighted averages of monthly mean data are combined, interpolated, and smoothed for each sampling location.
#  Hemispheric and global means are estimated by cosine weighting by latitude.
#  
#  This work was funded in part by the Atmospheric Chemistry Project of NOAA's Climate and Global Change Program.
#  
#  Citation:
#  Dutton, G.S., B.D. Hall, S.A. Montzka, J.D. Nance, S.D. Clingan, K.M. Petersen (2026), 
#     Combined Atmospheric Chloroflurocarbon-12 Dry Air Mole Fractions from the
#     NOAA GML Halocarbons Sampling Network, 1977-2026, Version: 2026-06-11,
#     https://doi.org/10.15138/PJ63-H440
#  
#  For contact information see https://gml.noaa.gov/about/stafflist.html
#  
#  Calibration scale used:  NOAA 2008
#  More information about the calibration scale can be found at: https://gml.noaa.gov/ccl/
#  
#  Global monthly data are provided in parts-per-trillion, ppt. 
#  
#  See (https://gml.noaa.gov/dv/site/?program=hats&active=1) more information on current
#  background air halocarbon sampling sites.
#  
#  alt = Alert, North West Territories, Canada (82.5N, 62.3W) (Atmospheric Environment Service Site) (flask only)
#  sum = Summit, Greenland (72.6N, 38.4W, 3210m)-GLASS FLASKS ONLY (flask and in insitu)
#  brw = Pt. Barrow, Alaska, USA (71.3N, 156.6W) (flask and in insitu)
#  mhd = Mace Head, Ireland (53N, 10W) (flask only)
#  thd = Trinidad Head, USA (41N, 124W, 120m) (flask only)
#  nwr = Niwot Ridge, Colorado, USA (40.052N, 105.585W) (University of Colorado site)(flask and in insitu)
#  kum = Cape Kumukahi, Hawaii, USA (19.5N, 154.8W) (flask only)
#  mlo = Mauna Loa, Hawaii, USA (19.5N, 155.6W)(flask and in insitu)
#  smo = Cape Matatula, American Samoa (14.3S, 170.6W)(flask and in insitu)
#  cgo = Cape Grim, Tasmania, Australia (40.7S, 144.8E) (CSIRO/Australia site) (flask only)
#  psa = Palmer Station, Antarctica (64.6S, 64.0W) (GLASS FLASKS ONLY)
#  spo = South Pole (90S)(flask and in insitu)
#  
#  See https://gml.noaa.gov/obop/ for station statistics and personnel.
#  
#  The last column of data is a six digit binary number that lists the measurement projects used in calculating
#  the combined hemispheric and global mean.s  A number 1 indicates data from the corresponding project was uses.
#  The binary number is arranged from left to right: oldGC, RITS, otto, CATS, CCGG, MSD
#  
#  oldGC = Original flask program started in 1977 at NOAA baseline observatories, expanded to 7 sites.
#  RITS = In-situ program started in 1987 at 4 stations (NWR added in 1990).
#  OTTO = New flask analysis GC installed in 1995, currently 13 background sample sites.
#  CATS = New in-situ GCs installed from 1998-2000 at 5 stations.  Summit, Greenland added in 2007.
#  CCGG = Carbon Cycle Gas Group flask program, a subset of sampling stations co-located with the "OTTO" program.
#  MSD = Flasks analyzed on a mass selective detector.
#  
#  nan = not a number or no data, and space(s) is the delimiter.
#  
#  The hemispheric and global mean error estimates are calculated using 1-standard deviation errors assigned to
#  the individual programs plus a systematic errors due to smoothing and interpolating.
#  
#  The combined data set is a weighted average of several background NOAA/GML measurement
#  programs. All programs are on the same NOAA scale and every attempt is made to correct known biases
#  between measurement programs; however, there maybe small differences that are not understood and
#  characterized. When comparing measurements from site to site, be aware that not all sites are
#  composed of the same measurement programs. The hemispheric and global means in the combined data set
#  are our best measure of long-term trends and are used for international and national assessments for
#  background air measurements.
#
